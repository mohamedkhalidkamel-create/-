# Lumé — متجر مستحضرات التجميل

موقع متجر إلكتروني كامل (HTML + CSS + JavaScript فقط، بدون قاعدة بيانات) يعرض
المنتجات ويتم إتمام الطلب بالكامل عبر واتساب.

## 1. التشغيل محلياً

المتصفحات لا تسمح لملف `fetch()` بقراءة ملفات من القرص مباشرة (`file://`)، لذلك
لازم تشغّلي سيرفر محلي بسيط (مافيش داعي لأي تنصيب معقد):

```bash
# داخل مجلد المشروع
python3 -m http.server 8080
```

بعدها افتحي المتصفح على: `http://localhost:8080`

(أو استخدمي إضافة "Live Server" في VS Code لو بتستخدميه)

## 2. أهم خطوة قبل النشر: رقم الواتساب

افتحي ملف `js/main.js` وغيّري السطر ده في الأعلى برقم الواتساب الحقيقي بتاع
المتجر (بكود الدولة، من غير علامة + ومن غير مسافات):

```js
const WHATSAPP_NUMBER = "201234567890"; // <-- غيّري الرقم ده
```

## 3. إزاي تضيفي منتج جديد

1. اختاري المجلد المناسب حسب الفئة والفئة الفرعية، مثلاً:
   `1_skincare/c_serums/`
2. حطي صورة المنتج بنفس نمط التسمية:

   ```
   اسم_المنتج_السعرEGP.jpg
   ```

   مثال: `Cerave_Hydrating_Serum_320EGP.jpg`

3. شغّلي الأمر ده مرة واحدة لتحديث بيانات المتجر:

   ```bash
   node scripts/generate-products.js
   ```

   هيقرأ كل الصور الموجودة في المجلدات، ويطلع منها ملف `products.json`
   اللي الموقع بيعرض المنتجات منه.

> ملاحظة مهمة: المتصفح مقدرش "يقرا محتويات مجلد" من تلقاء نفسه لأسباب أمنية،
> فالحل العملي هو إن سكريبت `generate-products.js` يعمل الفحص ده مرة واحدة
> على جهازك، ويحفظ النتيجة في `products.json` — وده اللي بيخلي فكرة "البيانات
> جوه اسم الصورة" شغالة فعلياً على موقع بدون سيرفر.

لو حبيتي تمسحي منتج، امسحي صورته من المجلد وشغّلي نفس الأمر تاني.

## 4. الفئات والفئات الفرعية

الأسماء العربية للفئات موجودة في أول ملف `scripts/generate-products.js`
(`CATEGORY_LABELS` و `SUBCATEGORY_LABELS`) — لو ضفتي مجلد فرعي جديد، ضيفي
اسمه العربي هناك برضه.

## 5. المميزات المتوفرة حالياً

- عرض المنتجات مقسمة حسب الفئة، مع شريط فئات قابل للتمرير.
- شريط بحث فوري بالاسم.
- ترتيب حسب السعر (تصاعدي/تنازلي) أو الاسم.
- سلة تسوق مع التحكم في الكمية (+ / -) وحذف المنتج.
- **حفظ السلة تلقائياً في `localStorage`** — لو العميل عمل Refresh للصفحة،
  سلته بتفضل زي ما هي.
- نموذج صغير لجمع (الاسم، الهاتف، العنوان) قبل إرسال الطلب.
- زر "إتمام الطلب عبر واتساب" بيبني رسالة جاهزة فيها كل المنتجات والكميات
  والإجمالي وبيانات التوصيل، ويفتحها في واتساب مباشرة.
- تصميم متجاوب (Responsive) يشتغل كويس على الموبايل.
- زر واتساب عائم للاستفسارات العامة.

## 6. هيكل الملفات

```
├── css/style.css              التنسيق العام
├── js/main.js                 كل منطق الموقع (سلة، بحث، فلترة، واتساب)
├── img/logo.png                شعار الموقع (تجريبي — استبدليه بشعارك)
├── products.json                ملف بيانات المنتجات (مُولَّد تلقائياً)
├── scripts/
│   ├── generate-products.js     يبني products.json من أسماء الصور
│   └── make_placeholders.py     (اختياري) يولّد صور تجريبية للعرض فقط
├── 1_skincare/ ... 7_offers/     مجلدات الفئات وصور المنتجات
└── index.html                   الصفحة الرئيسية
```

## 7. أفكار لتطوير لاحق (مش موجودة حالياً)

- ربط لوحة تحكم بسيطة لرفع صور المنتجات من المتصفح مباشرة بدل الرفع اليدوي.
- دعم عدة عملات أو خصومات تلقائية على الباقات.
- تتبع عدد الزيارات/المبيعات (يحتاج سيرفر أو خدمة تحليلات خارجية).
